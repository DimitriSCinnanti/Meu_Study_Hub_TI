# Meu Study Hub TI

## Sobre mim

Meu nome é **Dimitri Sofoulis Cinnanti** e sou estudante de **Ciência da Computação no UniCEUB**.

Criei este repositório para organizar meus materiais acadêmicos, atividades, projetos e acompanhar minha evolução durante a graduação.

Atualmente, meu principal foco profissional está ligado a **e-commerce, empreendedorismo e negócios digitais**, atuando diretamente com a **Cinnanti E-commerce** e a **Compre Já**.

A tecnologia também faz parte dessa rotina e utilizo os conhecimentos adquiridos durante a graduação para entender melhor sistemas, ferramentas digitais e desenvolver projetos próprios.

---

## Objetivo

O **Meu Study Hub TI** tem como objetivo reunir em um único lugar:

- Disciplinas da graduação;
- Atividades e trabalhos acadêmicos;
- Anotações e resumos;
- Projetos acadêmicos e pessoais;
- Certificados;
- Documentação;
- Histórico de versionamento.

O projeto também é utilizado para colocar em prática conhecimentos de **Git, GitHub, Markdown, HTML, CSS e GitHub Pages**.

## Fluxo de versionamento

O processo utilizado para atualização do projeto segue o fluxo:

```text
Alteração dos arquivos
        ↓
git add
        ↓
git commit
        ↓
git push
        ↓
GitHub
```

Os commits são utilizados para registrar as principais mudanças realizadas no projeto.

Alguns exemplos:

```text
Criação da estrutura inicial do Study Hub
```

```text
Adiciona documentação das disciplinas
```

```text
Cria versão 1.0 do Portfolio Web
```

```text
Publica Portfolio Web no GitHub Pages
```
