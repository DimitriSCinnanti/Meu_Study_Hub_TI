# Planejamento do Repositório

## Objetivo

O Meu Study Hub TI foi planejado para centralizar materiais acadêmicos, projetos pessoais, documentos e certificados. A ideia é manter uma estrutura simples, que possa continuar sendo usada durante os próximos semestres.

## Seções principais

### 01_Apresentacao_e_Perfil
Reúne uma apresentação pessoal, experiência profissional e formas de contato.

### 02_Disciplinas_Atuais
Organiza as disciplinas do semestre. Cada matéria possui uma pasta própria e pode receber atividades, entregas, anotações e resumos.

### 03_Projetos_e_Certificados
Reúne projetos pessoais ou acadêmicos e certificados de formação complementar.

### docs
Contém o portfólio web utilizado no GitHub Pages, além dos arquivos públicos da entrega.

## Padrão de organização das disciplinas

```text
Nome_da_Disciplina/
├── README.md
├── Atividades_e_Entregas/
└── Anotacoes_e_Resumos/
```

O padrão facilita a localização dos arquivos e evita que trabalhos de disciplinas diferentes fiquem misturados.
