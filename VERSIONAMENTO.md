# Versionamento do projeto

O repositório utiliza Git para registrar a evolução do Study Hub. As principais etapas foram separadas em versões para deixar claro o que mudou ao longo do projeto.

| Versão | Conteúdo principal |
|---|---|
| v1.0 | Estrutura inicial do Study Hub |
| v1.1 | Organização, documentação e READMEs |
| v1.2 | Portfólio web, GitHub Pages e entrega intermediária |

## Padrão de commits

Os commits devem ser curtos e descrever a alteração realizada. Exemplos:

```text
Cria estrutura inicial do Study Hub
Organiza disciplinas e atualiza READMEs
Adiciona portfolio web para GitHub Pages
Atualiza documentacao da etapa intermediaria
```
